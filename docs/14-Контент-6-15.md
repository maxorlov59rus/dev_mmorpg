## Инстансы
**Пещеры Испытаний (map 20, 5 игроков, сброс 24 ч)** — схема: Вход «Каменные челюсти» → 3 пака нетопырей/волчьих пауков → треш-зала → Алтарь Кадuka (босс). Вход через LFG; гейт — квест 1005 (проверка `instance_lock_check` + q_1005 в areatrigger_teleport).
**Крепость Пепла (map 5)** — хабу-санктуарий фракции Альянса: Двор вендоров (торговцы, тренинг), Черный рынок (ренегаты, открывается наградой 1012). PvP снят принудительно (Sanctuary).

## Архитектура связей (ядро ↔ БД ↔ клиент)
1. **БД**: `sql/upgrades/Insert_Quests_6_15.sql` — quest_template(12), quest_objective, creature_loot_template, gameobject_loot_template, areatable (инстанс/хаб), npc_quest_giver.
2. **Сервер**: `QuestLoader` (реестр+цепочки+цели), `CharacterHooks::AdvanceQuestObjectiveOnKill` (хук из AI), `CreatureAI::FillLoot` (детерминированный дроп xorshift64*). SELECT-контракты зафиксированы в комментариях модулей.
3. **Пакеты**: CMSG_QUEST_ACCEPT 0x2002 / SMSG_QUEST_ACCEPTED 0x2004 / SMSG_QUEST_PROGRESS 0x2005 (1 байт прогресса цели) / SMSG_QUEST_COMPLETE_RESULT 0x2006 / SMSG_QUEST_TURN_IN_HINT 0x2007 (proto/opcodes.defs v1.9 — уже реализованы и принимаются MMOPlayerController).
4. **Клиент**: `UI_QuestLogWidget` (журнал, кнопка «Выбрать специализацию» для 1004), `MMOQuestTrackerHUD`, DataTable `data/DT_Quests.csv` (тексты/локализация, RowName = quest id).
